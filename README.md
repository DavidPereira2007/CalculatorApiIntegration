# ClientServerCalculator

A simple client-server calculator using WinForms and ASP.NET Core Web API.

## About

This project was created for study purposes to practice:

- ASP.NET Core Web API
- WinForms
- HTTP requests
- API consumption with HttpClient
- Client-server architecture
- JSON communication between applications

The project consists of:

- `CalculatorAPI` → ASP.NET Core Web API responsible for calculations
- `CalculatorWinForms` → WinForms application that consumes the API

---

# Technologies

- C#
- .NET
- ASP.NET Core Web API
- WinForms
- HttpClient

---

# Project Structure

```text
ClientServerCalculator
 ├── CalculatorAPI
 └── CalculatorWinForms
```

---

# How to Run

## 1. Start the API

Open the `CalculatorAPI` project and run it.

The API must be running before starting the WinForms application.

---

## 2. Start the WinForms Application

Open the `CalculatorWinForms` project and run it.

The application will send HTTP requests to the API and display the calculation results.

---

# Features

- Addition
- Subtraction
- Multiplication
- Division
- Basic API error handling

---

# Notes

This is a simple educational project focused on learning API integration and client-server communication using C#.
